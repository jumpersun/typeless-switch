# Typeless Switch v0.1.0 · 20261013-132853

账号列表与切号稳定性更新。应用版本为 0.1.0，发布标签为 `v0.1.0-preview.20261013.132853`。

## 本次更新

- 侧栏「账号」入口改为人物轮廓图标。
- 「所有账号」展示全部已保存账号，包括当前账号；当前项显示标记，避免重复切换。
- 当前账号支持「移除保存记录」，保留 Typeless 的当前登录，之后可再次保存。
- 登录提示改为「检测到本地会话」，明确本地文件检查与服务端登录有效性的区别。
- 退出与启动辅助命令增加超时和进程回收。失败时尝试恢复原账号；辅助进程未结束或恢复未完成时，保留备份并阻止后续写入。

## 下载与安装

仅提供 **macOS Apple Silicon（M 系列 Mac）** 安装包：

- `Typeless-Switch-0.1.0-20261013-132853-macOS-AppleSilicon.zip`，3,190,079 字节。
- `SHA256SUMS.txt`：安装包校验值。

退出旧版 Typeless Switch，解压 ZIP，将 `Typeless Switch.app` 拖入「应用程序」替换旧版。账号库格式和应用标识保持不变，不需要删除原账号数据。

请先安装并登录 Typeless 官方客户端。切换会重启 Typeless，请先结束录音；切换后在官方客户端确认账号和语音输入正常。
