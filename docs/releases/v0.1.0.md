# Typeless Switch v0.1.0

Typeless 本地账号切换工具的首个预发布版。免费开源，采用 MIT 许可证。

## 下载与安装

本次仅提供 **macOS Apple Silicon（M 系列 Mac）** 安装包：

- `Typeless-Switch-0.1.0-20261011-131258-macOS-AppleSilicon.zip`
- `SHA256SUMS.txt`：安装包校验值。

退出旧版 Typeless Switch，解压 ZIP，将 `Typeless Switch.app` 拖入「应用程序」。已有账号库继续使用，无需删除账号数据。

安装前需要已安装并登录官方 Typeless 客户端。本包是普通桌面账号管理应用，使用真实本机账号，不是示例预览 App。

## 功能

- 保存、添加和一键切换已有账号。
- 登录状态在本机加密保存，支持更新会话、移除保存账号和失败恢复。
- 浅灰侧栏、字母头像，支持中文 / English 和浅色 / 深色 / 跟随系统。
- 无自建服务器，无遥测；不包含词库同步、邮箱工具或菜单栏 / 托盘模式。

切换会重启 Typeless，请先结束录音。登录状态过期时，请在官方客户端重新登录后更新会话。

## 验证范围

生产构建、安装包 CRC / SHA-256、解压文件一致性和 ad-hoc 签名校验已通过。核心隔离测试 18 项、偏好与翻译测试 4 项已通过。

本版本未经 Apple 公证，完整原生 UI 和真实双账号切换验收仍待完成，因此标为预发布版。Windows 适配代码已包含，本次不提供 Windows 安装包。
